Features

주요 기능

인천공항 전 구역을 위한 8가지 핵심 기능

실내 지도

T1, T2, 탑승동 및 빌딩별 층수로 나누어 전 구역 실내 지도 구현

길찾기

출발·도착·경유지 선택 가능한 최적 경로 탐색 및 안내

실시간 내 위치

블루투스 기반 포그라운드 서비스로 실시간 사용자 위치 표시

경로 시뮬레이션

출발 전 전체 경로를 미리 확인할 수 있는 시뮬레이션

검색

원하는 장소를 빠르게 찾는 POI 검색 페이지

카테고리

카테고리 선택 시 POI 강조 및 카메라 자동 이동

LOD 시스템

줌 레벨에 따른 마커 우선순위 기반 LOD, 낮은 우선순위 fade-out

튜토리얼

처음 사용자를 위한 온보딩 튜토리얼 화면 구현

Tech Stack

기술 구현

성능과 사용성을 위한 핵심 기술 선택

Android Kotlin Google Maps SDK GeoJSON GitHub Actions ProGuard

Indoor Map · GeoJSON

인천공항 전용 GeoJSON 기반 T1·T2·탑승동 각 층 실내 지도 적용. TileProvider + LRU Cache로 비트맵 타일 변환·캐싱하여 렌더링 성능 최적화

Pathfinding · Dijkstra

노드·경로 데이터 기반 그래프 구축, 다익스트라 알고리즘으로 최적 경로 탐색. 경유지 및 Switch 구조 지원

LOD System · POI

우선순위 기반 LOD 시스템으로 줌 레벨에 따른 마커 표시 제어. POI 근접 탐색 및 해상도별 마커·텍스트 크기 자동 조정

Background Service · BLE

블루투스, 포그라운드 서비스, 배터리 최적화 권한으로 백그라운드 실시간 위치 동작 지원

Data Loading Strategy

초기 로딩 시 로컬 assets 우선 사용, 이후 백그라운드에서 최신 데이터 갱신하는 하이브리드 로딩 전략

CI/CD · Security

GitHub Actions 조건부 자동 배포 파이프라인 구성. ProGuard 코드 난독화 적용
