Focus Cycle

집중의 흐름

4단계로 완성하는 방해 없는 집중 루틴

🎯

STEP 01

상황 선택

학습·업무·독서 등 집중 목적 설정

🚫

STEP 02

앱 차단

방해 앱 선택 후 즉시 or 예약 차단

⏱️

STEP 03

집중 실행

타이머 동안 방해 없이 몰입

📊

STEP 04

회고 · 리포트

몰입도 기록 & 주간 인사이트 확인

Features

주요 기능

집중부터 회고까지, 몰입을 돕는 4가지 기능

🎯

집중 상황 선택

학습, 업무, 독서 등 집중하고 싶은 상황을 직접 선택하여 목적에 맞는 집중 모드 시작

🚫

앱 차단 타이머

방해되는 앱을 선택하고 지금 바로 차단하거나, 원하는 시간에 자동으로 차단 예약 가능

즉시 시작 / 예약
🔍

집중 실험 회고

집중을 마친 후 간단한 회고로 몰입도를 기록. 작은 회고들이 쌓여 나만의 집중 습관 발견

📈

주간 집중 리포트

집중 시간, 몰입도, 가장 많이 몰입한 활동 등을 주간 단위 인사이트로 제공

Tech Stack

기술 구현

앱 차단과 집중 분석을 위한 핵심 기술

🚫

AccessibilityService · App Blocking

AccessibilityService를 활용한 포그라운드 앱 감지 및 차단 제어. PackageManager로 사용자 설치 앱 목록 획득

⏰

AlarmManager · 예약 차단

AlarmManager를 통해 앱이 종료된 백그라운드 상태에서도 특정 시각에 Block 모드 자동 ON/OFF 구현

📊

UsageStatsManager · 사용량 분석

일·월·년 단위 앱 사용량 데이터 수집. 주간 리포트 및 집중 인사이트 제공에 활용

🎨

Jetpack Compose · MVI

선언형 UI 패턴과 MVI 아키텍처로 단방향 데이터 흐름 및 상태 관리 구현

Architecture

멀티 모듈 구조

관심사 분리를 위한 3계층 모듈 설계

:data

Repository, DataSource, 로컬 DB, 외부 API 연동

:domain

UseCase, 비즈니스 로직, 순수 Kotlin 모듈

:feature

화면별 독립 모듈, Compose UI + ViewModel

⚙️ Build-Logic을 통한 build.gradle 공통 로직 공유로 모듈별 빌드 설정을 체계적으로 관리
